Сюда кладите свои ролики и фото.

1. Скопируйте видео сюда, например: concert.mp4
   (лучше MP4, вертикальное 9:16, до 15–20 МБ, чтобы сайт быстро грузился)

2. Откройте index.html, найдите блок WORKS и впишите путь:
   { title: "Концерт · ночь в Алматы", cat: "concerts", video: "works/concert.mp4", ... }

3. Ссылку на рилс можно добавить в поле link — тогда по ней будет вести кнопка.

Категории (cat): concerts, cars, drone, content
Своё фото для блока «Обо мне»: CONFIG.portrait = "works/me.jpg"
Шоурил в телефоне на главном экране: CONFIG.heroVideo = "works/showreel.mp4"
WhatsApp: CONFIG.whatsapp = "77001234567"
